# Pizzeria Da Marco

En webbplats för den fiktiva familjepizzerian **Da Marco**, byggd med HTML och CSS. Webbplatsen består av flera sidor: startsida, om oss, meny och en beställningssida.

## Om projektet

Det här är ett skolprojekt (miniprojekt) som gjorts inom kursen **Frontend 1**. Syftet är att öva på att bygga en statisk webbplats med semantisk HTML och CSS, navigering mellan flera sidor samt ett formulär.

## Sidor

- **Hem** (`index.html`) – Startsida med hero-bild, kort presentation och öppettider.
- **Om oss** (`om.html`) – Pizzerians historia samt leveransinformation.
- **Meny** (`meny.html`) – Översikt över pizzor med bilder, ingredienser och priser.
- **Beställ** (`beställ.html`) – Beställningsformulär med namn, telefon, adress, pizzaval och kommentar.

## Tekniker

- HTML5
- CSS3
- Google Fonts (Imperial Script & Quicksand)

## Kör projektet lokalt

Projektet är helt statiskt och behöver ingen installation eller server.

1. Klona eller ladda ner detta repo:
   ```bash
   git clone <repo-url>
   ```
2. Gå in i projektmappen:
   ```bash
   cd Grupp-4-Pizzeria-Da-Marco
   ```
3. Öppna `index.html` i din webbläsare – dubbelklicka på filen eller högerklicka och välj "Öppna med" din webbläsare.

> **Tips:** Använder du Visual Studio Code kan du installera tillägget **Live Server** och välja "Go Live" för att köra sidan med automatisk uppdatering.
